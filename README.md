# CRIA Website

Website moderno desenvolvido com **React**, **JavaScript** puro e **CSS** puro.

## 📁 Estrutura do Projeto

```
CRIA-test/
├── public/
│   └── index.html           # HTML principal
├── src/
│   ├── components/          # Componentes React
│   │   ├── Header.jsx       # Cabeçalho
│   │   ├── Hero.jsx         # Seção principal
│   │   └── Footer.jsx       # Rodapé
│   ├── pages/              # Páginas (para futuro)
│   ├── styles/             # Estilos CSS
│   │   ├── global.css      # Estilos globais
│   │   ├── App.css         # Estilos da App
│   │   ├── Header.css      # Estilos do header
│   │   ├── Hero.css        # Estilos do hero
│   │   └── Footer.css      # Estilos do footer
│   ├── App.jsx             # Componente principal
│   └── main.jsx            # Entrada da aplicação
├── package.json            # Dependências
├── vite.config.js          # Configuração Vite
└── README.md               # Esta documentação
```

## 🚀 Como Iniciar

### 1. Instalar as dependências
```bash
npm install
```

### 2. Rodar em desenvolvimento
```bash
npm run dev
```

### 3. Build para produção
```bash
npm run build
```

## 📦 Tecnologias Utilizadas

- **React 18** - Biblioteca UI
- **Vite** - Build tool rápido
- **CSS Puro** - Sem pré-processadores
- **JavaScript ES6+** - Sem frameworks adicionais
